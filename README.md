# AI/ML Foundations – Colab Assignment

This repository contains the completed Colab notebooks for the AI/ML foundations assignment.

Each notebook was copied, executed, and saved with its inputs and outputs. The notebooks cover the fundamental concepts required for understanding AI, machine learning, tensors, neural networks, and basic deep-learning architectures.

For each notebook, I have also recorded a short explanation video covering the key concepts, important code blocks, and their outputs.
